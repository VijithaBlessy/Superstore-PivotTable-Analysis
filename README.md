# Superstore PivotTable Analysis

## Project Overview
This project uses Excel PivotTables to analyze Superstore sales data.

## Objective
To summarize and compare sales by category, region, and month.

## Tools Used
- Microsoft Excel
- Superstore Dataset

## Analysis Performed
1. Sales by Category
2. Sales by Region
3. Sales by Month

## Key Insights
- Technology recorded the highest sales among the three product categories.
- West recorded the highest sales among the four regions.
- November recorded the highest monthly sales, while February recorded the lowest.

## Outcome
Excel PivotTables helped summarize the dataset and identify sales patterns quickly.
